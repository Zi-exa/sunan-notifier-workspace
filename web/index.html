Cara install (2 menit)

  1. Klik Download dari HP Android, tunggu selesai.
  2. Buka file-nya, klik Install. Kalau ada peringatan Play Protect, pilih Tetap install.
  3. Buka aplikasi → login pakai NIM + password SUNAN. Izinkan notifikasi.

Buka web ini di laptop? Scan QR dari HP.
